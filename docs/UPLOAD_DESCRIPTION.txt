Supplementary code and numerical data for the fixed-budget visual world-model study. Includes original experiment scripts, frozen protocol and source manifests, nine-checkpoint latent/physical evaluation reports and ridge-decoder parameters, non-image simulator state/action arrays for four conditions, training metadata, and CPU-only numerical reproduction tools. Full RGB trajectories, source expert HDF5, and world-model checkpoint weights are not included; requirements and limitations are documented in README.txt.
